# WasteLink PH — Optimized PWA

A high-performance Progressive Web App for informal waste pickers in the Philippines.

## ✨ Features
- **Offline-First**: Works without internet via Service Worker and IndexedDB.
- **Installable**: Full PWA support for Android (Chrome) and iOS (Safari).
- **Mobile Optimized**: Thumb-friendly navigation and safe-area support.
- **Fast Build**: Powered by React + Vite.

## 🚀 Quick Start
```bash
npm install
npm run dev
```

## 📦 Build & Deploy
```bash
npm run build
npx vercel deploy --prod
```

## 🛠 Tech Stack
- React 18
- Vite
- IndexedDB (idb)
- Custom Service Worker
- Pure CSS (Mobile-optimized)
